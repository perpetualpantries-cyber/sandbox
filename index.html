Cafés in this browser

Each café has its own PP app and its own data. Set up a new one here, or reopen one you’ve already set up in this browser.

+ Set up a new café

A new café opens blank, not connected to anything. In its Settings, enter the PP server URL below and the link code from PP Command → Sites.

Connecting the apps to the server

Each app has a Settings section. Put this server address there:

https://pp-backend-staging.vercel.app
  1. PPcanopy: sign in with your staff email and password. Your data then saves to the server and is shared with everyone signed in.
  2. PP Command: enter the one-time linking code from PPcanopy (Clients & Venues → Get linking code).
  3. PP: enter the one-time linking code from that client's PP Command (Sites → Generate link code).

Linking codes are single-use and expire after 24 hours. If one runs out, generate a new one.
